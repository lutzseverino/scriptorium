# Repository license rules

The repository's license lives in one root file, `LICENSE`, whatever the
repository's visibility. No other root license file, such as `LICENSE.md`, sits
beside it.

`LICENSE` holds a single, clear license: the text of the license the maintainer
named, with the maintainer's copyright notice where the license carries one. A
maintainer may grant no license; `LICENSE` then states the copyright holder and
that all rights are reserved. The license is the maintainer's decision: never
select or infer one.

The Repository README's License link matches `LICENSE`, as the
[`repository-readme` rules](repository-readme.md) state.
