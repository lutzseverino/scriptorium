# Project README adoption guidance

Bring the Project README at each confirmed path into line with the
`project-readmes` rules. Preserve useful and accurate existing content. Assess
purpose, commands, configuration, and links against repository evidence.

The read-only structural check verifies the title, local links, and resolving
links to the root `CONTRIBUTING.md` and `docs/development/README.md` for each
confirmed path, including that each shared link renders text or visible linked
media. It does not decide Project membership, establish semantic accuracy, or
detect duplication of shared instructions.
