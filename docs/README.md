# Factory documentation

This directory maps the factory's documentation categories.

- [Usage](usage/README.md): installing and configuring the factory on a host,
  and the files a repository it serves provides.
- [Development](development/README.md): setting up, testing and releasing the
  package, and maintaining its pinned tools.
- [Architecture decisions](adr/README.md): consequential decisions about the
  factory and their rationale.
- [Agent configuration](agents/README.md): the skill setup files agents read
  as this repository's workflow configuration.
